Kituwa Cluster Earn

Programme rules

These are the rules as the system actually enforces them. Where a number can change, the live page shows the current value.

Earning

  • One point is one CPU-second of real work performed for Kituwa, measured by the worker's points agent. Completed work units add the published bonus: {{ programme.get('job_points', {}).get('job_run', 10) }} points for a scheduled job, {{ programme.get('job_points', {}).get('deploy', 25) }} for a deployment, {{ programme.get('job_points', {}).get('build', 50) }} for a build.
  • Volunteer machines earn only while idle. The idle gate cordons a node when its load crosses 60% of its cores, so nothing new is scheduled while you are using the machine. Running pods are not killed.
  • Only linked nodes earn for an account. Linking records the node's current published total as the baseline; only work after that moment is credited to you. Points already in the ledger before linking stay with the cluster.
  • One account per person. The default node limit is one; the operator can raise it for a member who runs several machines. Claim codes are single-use and expire after 30 minutes.
  • The ledger wins. Credit is the difference between two published per-node totals. A missing or stale publication credits nothing; it is never estimated.

Redeeming

  • Premium is the only reward. There are no physical goods, no shipping and no address collection. Every reward is digital time on Kituwa Premium.
  • Issued immediately. The cost is deducted and the premium token is created in one transaction. Time stacks on an active grant.
  • Email must be confirmed before any redemption. Earning can start before confirmation.
  • Cancellation. The operator can cancel a grant for a full point refund and revoke the token; a revocation for abuse does not refund. Once a token has been used elsewhere, cancelling it stops future checks but cannot erase access already granted.

What points are not

Points are a loyalty credit, not money, a security, a token on a chain or an investment. They cannot be sold, transferred or exchanged for cash, and they confer no ownership or governance right. The programme can be paused or changed; accrued points are honoured for redemption while it runs.

Fair use

Claim only machines you own or are authorised to operate. Automating signups, farming idle nodes you do not control, or manipulating the ledger is grounds for removing the account and its balance. The operator can adjust a balance with a written reason; every adjustment is in the audit log.
