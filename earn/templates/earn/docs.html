Integration

Earn API

Read-only summary for the public; premium verification for partner sites; a one-time claim endpoint for machines. No endpoint accepts a password or a session cookie from another origin.

Public summary

GET {{ origin }}/api/v1/earn/summary

Members, linked nodes, points earned and redeemed. Cache for five minutes.

Verify premium

POST {{ origin }}/api/v1/earn/premium/verify
Content-Type: application/json

{"token":"kprem_…"}

Answers {"active":true,"site":"premium","plan":"premium", "expires_at":"2026-12-23T00:00:00Z"} or {"active":false}. Call it server-side. Never put a token in a page, a referrer URL or a log line.

Claim a node

POST {{ origin }}/api/v1/earn/claim
Content-Type: application/json

{"code":"k3sclaim_…","node":"spare-pc"}

The code is issued in the member's account, expires after 30 minutes and works once. The node must already appear in the published points snapshot. This is the endpoint used by claim.sh; it is not for browsers.

Auth methods

GET {{ origin }}/.well-known/auth-methods.json

Operating notes

  • The worker computes points, publishes a snapshot to the host every five minutes; the host records deltas and holds accounts, sessions and redemptions.
  • All write endpoints are same-origin and CSRF-protected except the one-time claim code, which is its own bearer credential.
  • Sessions are server-side, host-only, Secure and HttpOnly. Passwords are Argon2id. Email verification and password reset are single-use links.
  • No third-party JavaScript runs on account or redemption pages.
