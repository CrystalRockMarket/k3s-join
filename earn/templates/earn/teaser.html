The chart shows measured machine earnings. A member balance can also include one-time welcome and founder credits, so it is not the same number.

These are caps, not guarantees: the machine earns only for measured work the cluster actually schedules on it. A laptop that is being used earns nothing, which is why its line can stay almost flat.

How earning works

1 · Join

Bring a machine

Use a join code to add a spare Linux box, Mac or Windows PC. The node earns only while it is idle, so your own work always comes first.

2 · Link

Claim your node

Create an account, then run one command on the machine. The claim proves you control it, and the node starts crediting your balance.

3 · Redeem

Premium time

Spend points on Kituwa Premium. The token unlocks the member area here and is accepted by each site as it connects to the verifier.
