How earning works

1 · Join

Bring a machine

Use a join code to add a spare Linux box, Mac or Windows PC. The node earns only while it is idle, so your own work always comes first.

2 · Link

Claim your node

Create an account, then run one command on the machine. The claim proves you control it, and the node starts crediting your balance.

3 · Redeem

Premium time

Spend points on Kituwa Premium. The token unlocks the member area here and is accepted by each site as it connects to the verifier.
