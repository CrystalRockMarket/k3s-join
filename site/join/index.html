Join in one command

The launcher asks the cluster for a one-use key, installs the worker and opens a live panel. You never paste a code, create an account or wait for an email.

Linux with systemd. The command downloads a small script and runs it — you do not need to install anything first.

  1. Open a terminal. Press Ctrl+Alt+T, or open your apps menu and type Terminal. A black window with a prompt appears.
  2. Paste the command. Copy it with the button below, then in the terminal press Ctrl+Shift+V (a plain Ctrl+V usually does not paste into a terminal) or right-click → Paste.
  3. Press Enter and wait. It asks for your login password — type it and press Enter. Nothing appears on screen while you type your password; that is normal, not a freeze.
  4. Leave the window open. A live panel shows points and load. Closing it does not stop the worker; it runs as a service and starts on boot.
curl -fsSL https://k3s.kituwa.com/linux -o kituwa-join.sh && bash kituwa-join.sh
What sudo, chmod, ./ and “command not found” mean

sudo means “run this as the administrator”. It is why you are asked for your password. You do not type sudo yourself here — the command above already includes it where it is needed.

bash kituwa-join.sh means “run the file kituwa-join.sh with the bash program”, so the file does not have to be marked executable. If you downloaded the file yourself instead (for example into Downloads) and want to run it directly:

cd ~/Downloads
chmod +x kituwa-join.sh
./kituwa-join.sh

chmod +x marks the file as executable — Linux will not run a downloaded file until it is. ./ means “the file in this folder”: without it the shell searches the system folders for a program called kituwa-join.sh and reports command not found. So ./kituwa-join.sh works, kituwa-join.sh alone usually does not.

Permission denied means step chmod +x was skipped. curl: command not found means the tool curl is missing — install it with sudo apt install curl (Debian/Ubuntu) or sudo dnf install curl (Fedora).

Windows 10 or 11. The command downloads a small script and runs it; the script sets up WSL2 with systemd and joins the same way as Linux.

  1. Open PowerShell as administrator. Click Start, type PowerShell, right-click Windows PowerShell and choose Run as administrator, then Yes. The window title must start with “Administrator”.
  2. Paste the command. Copy it with the button below, then press Ctrl+V in the window, or right-click inside it.
  3. Press Enter and wait. Windows may ask to enable features and restart — save your work first, then run the command again after the restart.
  4. Leave the window open. The panel shows progress and points. Closing it does not stop the worker.
irm https://k3s.kituwa.com/windows -OutFile "$env:TEMP\kituwa-join.cmd"; & "$env:TEMP\kituwa-join.cmd"
What irm, & and the PowerShell warnings mean

irm is short for Invoke-RestMethod: it downloads a file. -OutFile "$env:TEMP\kituwa-join.cmd" saves it in your temporary folder instead of printing it.

& is PowerShell’s “run this” operator — it tells Windows the text is a file path to execute, not a program name. Without it, a path is just printed as text. & "C:\...\kituwa-join.cmd" runs that file.

“Running scripts is disabled on this system”: allow them for this one window only, then paste the command again:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Rather double-click a file? Download kituwa-join-1.9.0.cmd, double-click it, and if Windows shows “Windows protected your PC”, choose More info → Run anyway. That is SmartScreen warning about a downloaded file, not an error.

macOS 13 or newer, Intel or Apple silicon. k3s is Linux-only, so the script installs a small Linux virtual machine (Lima) on your Mac and joins that. Your Mac itself is not modified beyond that.

  1. Open Terminal. Press ⌘+Space, type Terminal, press Enter.
  2. Paste the command. Copy it with the button below, then press ⌘+V in the Terminal window.
  3. Press Enter and wait. It asks for your Mac password — type it and press Enter. Nothing appears while you type; that is normal. It may also ask you to install developer command-line tools: say yes.
  4. Leave the window open. The panel shows progress and points. Closing it does not stop the worker.
curl -fsSL https://k3s.kituwa.com/mac -o kituwa-join.command && bash kituwa-join.command
What chmod +x, ./ and the macOS warnings mean

bash kituwa-join.command means “run this file with bash”, so you never need chmod or ./ with the command above. If you downloaded the .command file yourself, you can also double-click it in Finder — that is what the .command ending is for.

To run a downloaded file from Terminal instead, you first mark it executable and then run it by path:

cd ~/Downloads
chmod +x kituwa-join.command
./kituwa-join.command

chmod +x marks the file as executable; ./ means “the file in this folder”. Without ./ the shell looks for a system program of that name and says command not found; without chmod +x it says permission denied.

“cannot be opened because the developer cannot be verified” (Gatekeeper): right-click the file → Open → Open, or use the Terminal commands above. “command not found: curl” means the command-line tools are missing; the command above installs them for you when it asks.

The panel stays open after install and shows points, load and the time until the machine is considered idle. Closing the panel never stops the worker: it runs as a service and starts on boot. To stop it: sudo systemctl stop k3s-agent && sudo systemctl disable k3s-agent.

Want to share spare disk as well as CPU? Tick the storage pilot box in the form below. It reserves 50–500 GB in a dedicated folder, encrypted, and durable data is only accepted when three machines hold a copy. You can pause or remove it at any time; no storage is taken until the pilot opens.

What happens when you run it

  1. It checks the machine

    Linux with systemd, a supported architecture, 2 GB of RAM and 8 GB free on /var. It refuses rather than half-installs.

  2. It gets a one-use key

    The launcher asks this site for a key scoped to a single worker. The key is not stored in your browser and is never emailed.

  3. It joins the tailnet and the cluster

    Tailscale is installed from its official script; k3s runs in agent mode, version-pinned and checksum-verified.

  4. It stays on the panel

    Points earned, current load against the idle threshold, and the computed time until the cluster may schedule work. q closes the panel only.

  5. It earns only while idle

    A volunteer node is tainted and the idle gate cordons it when you are using it. Nothing is killed mid-task; new work simply waits.
