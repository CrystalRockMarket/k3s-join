Join in one command

The launcher asks the cluster for a one-use key, installs the worker and opens a live panel. You never paste a code, create an account or wait for an email.

Linux

Open Terminal (usually Ctrl+Alt+T), paste the line, press Enter.

curl -fsSL https://k3s.kituwa.com/linux -o kituwa-join.sh && bash kituwa-join.sh

macOS

Open Terminal (⌘+Space, type “Terminal”), paste the line, press Enter.

curl -fsSL https://k3s.kituwa.com/mac -o kituwa-join.command && bash kituwa-join.command

Windows

Open PowerShell as administrator (right-click Start), paste, press Enter.

irm https://k3s.kituwa.com/windows -OutFile "$env:TEMP\kituwa-join.cmd"; & "$env:TEMP\kituwa-join.cmd"

The panel stays open after install and shows points, load and the time until the machine is considered idle. Closing the panel never stops the worker: it runs as a service and starts on boot. To stop it: sudo systemctl stop k3s-agent && sudo systemctl disable k3s-agent.

What happens when you run it

  1. It checks the machine

    Linux with systemd, a supported architecture, 2 GB of RAM and 8 GB free on /var. It refuses rather than half-installs.

  2. It gets a one-use key

    The launcher asks this site for a key scoped to a single worker. The key is not stored in your browser and is never emailed.

  3. It joins the tailnet and the cluster

    Tailscale is installed from its official script; k3s runs in agent mode, version-pinned and checksum-verified.

  4. It stays on the panel

    Points earned, current load against the idle threshold, and the computed time until the cluster may schedule work. q closes the panel only.

  5. It earns only while idle

    A volunteer node is tainted and the idle gate cordons it when you are using it. Nothing is killed mid-task; new work simply waits.
