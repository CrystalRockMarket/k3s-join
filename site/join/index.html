Ask for a join code

One short form. It goes straight into the high-priority inbox, and I answer by email. Tell me what the machine is and what you would like it to do — that is all I need to decide.

Only used to reply and to send the join code.

10 characters minimum. Plain text, no links needed.

Sending puts it at the top of the inbox with a Telegram alert. No account, no marketing list.

What happens next

  1. It lands as high priority

    Every form submission is flagged and pushed to my phone and inbox the moment it arrives.

  2. I read it and reply

    Usually within a day. If it is a fit, the reply carries a join code for that machine.

  3. You run one command

    The code is a single line. Paste it where the installer asks; nothing else is needed.

  4. You can leave any time

    One uninstall command. No notice, no questions.
