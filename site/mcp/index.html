Model Context Protocol

The cluster as tools.

A read-only MCP server for the Kituwa k3s cluster. Ask for the worker count, the live points leaderboard or the Earn totals — over JSON-RPC 2.0 on HTTPS, with the same bearer key as the API.

What it is

The server speaks the Model Context Protocol over HTTP at https://k3s.kituwa.com/mcp. It is stateless: send a JSON-RPC 2.0 request, get a JSON-RPC response. Authentication is Authorization: Bearer k3s_…, the same key the HTTPS API uses. Nothing here writes cluster state.

Tool 1

cluster_summary

Worker count, live points, snapshot freshness and the points rule.

Tool 2

points_leaderboard

The public points snapshot: totals and the top worker nodes.

Tool 3

earn_stats

Verified members, linked nodes, points earned and redeemed.

Quick start

  1. Create an Earn account and verify your email.
  2. Create a key at /account/api-keys/. Copy it once.
  3. Point an MCP client at https://k3s.kituwa.com/mcp with the bearer header.

Initialize

POST /mcp
Authorization: Bearer k3s_…
Content-Type: application/json

{"jsonrpc":"2.0","id":1,"method":"initialize",
 "params":{"protocolVersion":"2025-06-18","capabilities":{},
 "clientInfo":{"name":"my-client","version":"1.0.0"}}}

List the tools

{"jsonrpc":"2.0","id":2,"method":"tools/list"}

Call a tool

{"jsonrpc":"2.0","id":3,"method":"tools/call",
 "params":{"name":"cluster_summary","arguments":{}}}

The result is a text content block containing the JSON data. The same key and rate limit apply: 120 requests per minute, then 429 with Retry-After.

Discovery

The server card is published at /.well-known/mcp.json. It names the endpoint, the transport, the auth header, the three tools and the free API. The HTTPS API is documented at /api/docs/, and the API page is /api/.

curl -sS https://k3s.kituwa.com/.well-known/mcp.json | head
