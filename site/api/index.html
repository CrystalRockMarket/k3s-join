Developer access

The cluster as data.

A small, read-only HTTPS API for the Kituwa k3s cluster: worker count, live points, the public leaderboard and Earn programme totals. One bearer key per caller, free to use, and the same three tools over MCP.

What you get

Every endpoint is a GET, returns JSON, and never writes cluster state. The points snapshot is produced on the worker; the API only reads the published copy.

EndpointWhat it returns
GET /api/v1/public/clusterWorker count, live points, snapshot freshness and the points rule.
GET /api/v1/public/pointsThe public points totals and the top worker nodes.
GET /api/v1/public/earnVerified members, linked nodes, points earned and redeemed.
GET /api/v1/public/healthService health; no key required.

The MCP server exposes the same data as cluster_summary, points_leaderboard and earn_stats. See /mcp/.

Get a key

  1. Create an Earn account at /account/signup/ and verify your email.
  2. Open /account/api-keys/.
  3. Create a key. It is shown once; copy it then. Only its hash is stored.

Send it as a header, never in a URL:

curl -H "Authorization: Bearer k3s_…" \
  https://k3s.kituwa.com/api/v1/public/cluster

Revoke a key at any time from the same page. A revoked key answers 401 on the next request.

Errors

StatusCodeMeaning
401missing_key / invalid_keyNo bearer key, or the key is unknown or revoked.
403forbiddenThe key does not carry the read scope.
429rate_limitedMore than 120 requests per minute for this key and address. Retry-After is set.
404not_foundNo such endpoint. See the docs for the exact paths.

Every error body carries error.code, error.message and a link to the docs.
