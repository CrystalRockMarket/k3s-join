API docs

Every endpoint, every error.

Base URL: https://k3s.kituwa.com/api/v1/public. Read-only JSON over HTTPS. The MCP server is at https://k3s.kituwa.com/mcp.

Authentication

Create a key at /account/api-keys/. Send it as a bearer header:

Authorization: Bearer k3s_<prefix>_<secret>

Keys are scoped to read, stored as a SHA-256 hash, revocable, and carry a last-used timestamp. Never put a key in a URL, a query string, a screenshot or a public issue. A missing, unknown or revoked key answers 401; a key without the read scope answers 403.

Rate limit

The API is free. There is no monthly call counter and no price. A per-minute rate limit protects the service: 120 requests per minute per key and client address.

Over the rate limit the API answers 429 with Retry-After. A key can be revoked at any time from the account page.

Endpoints

GET /api/v1/public

Service index. No key required.

{"ok":true,"service":"K3s Join & Earn API","version":"1.0.0",
 "auth":"Authorization: Bearer <key>","scope":"read",
 "endpoints":{"health":"/api/v1/public/health", ...},
 "docs":"https://k3s.kituwa.com/api/docs/"}

GET /api/v1/public/health

Health probe. No key required.

{"ok":true,"service":"k3s-join-api","version":"1.0.0","time":"2026-11-24T03:00:00Z"}

GET /api/v1/public/cluster

Key required. Worker count, live points, snapshot freshness and the points rule.

{"ok":true,"data":{"nodes":2,"live_points":421.4,"total_points":421.4,
 "generated_at":"2026-11-24T03:11:30Z",
 "rule":"1 point = $1 of Kituwa credit; 1 point per 384 CPU-hours of measured work; volunteers earn only while idle"},
 "meta":{"scope":"read","docs":"https://k3s.kituwa.com/api/docs/"}}

GET /api/v1/public/points

Key required. The public points snapshot and the top worker nodes.

{"ok":true,"data":{"generated_at":"2026-11-24T03:11:30Z",
 "total_points":421.4,"live_points":421.4,
 "nodes":[{"node":"airdrop-vivobook","points":261.8,"share":62.1,
 "last_seen":"2026-11-24T03:01:09Z"}]},"meta":{...}}

GET /api/v1/public/earn

Key required. Verified members, linked nodes, points earned and redeemed.

{"ok":true,"data":{"members":12,"nodes":2,"earned":421.4,"redeemed":0,
 "updated_at":"2026-11-24T03:00:00Z"},"meta":{...}}

Errors

StatusCodeMeaning
400bad_requestThe request body or parameter is not valid.
401missing_keyNo bearer key was sent.
401invalid_keyThe key is unknown or revoked.
403forbiddenThe key lacks the read scope.
404not_foundNo such endpoint.
429rate_limitedMore than 120 requests per minute; Retry-After: 60.

Error shape:

{"ok":false,"error":{"code":"rate_limited",
 "message":"Too many requests; slow down.",
 "docs":"https://k3s.kituwa.com/api/docs/#errors"}}

MCP server

The same data is exposed as an MCP server over HTTP at https://k3s.kituwa.com/mcp. It speaks JSON-RPC 2.0 and uses the same bearer key. The server card is at /.well-known/mcp.json; the human page is /mcp/.

Tools: cluster_summary, points_leaderboard, earn_stats.

POST /mcp
Authorization: Bearer k3s_…
Content-Type: application/json

{"jsonrpc":"2.0","id":1,"method":"tools/list"}
{"jsonrpc":"2.0","id":1,"result":{"tools":[
 {"name":"cluster_summary","description":"Worker count, live points and snapshot freshness."},
 {"name":"points_leaderboard","description":"The public points snapshot and top nodes."},
 {"name":"earn_stats","description":"Public Earn programme totals."}]}}
{"jsonrpc":"2.0","id":2,"method":"tools/call",
 "params":{"name":"cluster_summary","arguments":{}}}

Key management

Key management uses your Earn session, not a bearer key:

  • GET /account/api-keys/ — list your keys and prefixes.
  • POST /account/api-keys/ — create a key; the plaintext is shown once.
  • POST /account/api-keys/<id>/revoke — revoke a key.

The session form requires the CSRF token from the page. Keys are created only for verified accounts; five creations per hour per account.
